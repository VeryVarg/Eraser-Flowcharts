# Eraser-Flowcharts

A repository for storing and documenting flowcharts and diagrams created with [Eraser.io](https://eraser.io).

## 📁 Repository Structure

```
.
├── flowcharts/         # Store your .eraserdiagram files here
├── exports/            # Exported images (PNG, SVG, etc.)
├── docs/              # Additional documentation
└── templates/         # Templates for common flowchart types
```

## 🚀 Getting Started

### Adding a New Flowchart

1. Create your flowchart in [Eraser.io](https://eraser.io)
2. Export the diagram file (`.eraserdiagram` or diagram code)
3. Add it to the appropriate directory in `flowcharts/`
4. Export visual representations (PNG/SVG) to `exports/`
5. Update the documentation with a description and link

### Organization

Organize your flowcharts by project, category, or topic:

```
flowcharts/
  ├── project-name/
  │   ├── architecture.eraserdiagram
  │   └── workflow.eraserdiagram
  ├── system-design/
  └── processes/
```

## 📝 Documentation

Each flowchart should include:
- **Title**: Clear, descriptive name
- **Description**: What the flowchart represents
- **Purpose**: Why this flowchart exists
- **Last Updated**: Date of last modification
- **Link**: Link to Eraser.io (if applicable)

See `templates/FLOWCHART_TEMPLATE.md` for a documentation template.
