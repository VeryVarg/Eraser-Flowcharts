# Documentation

This directory contains additional documentation, guides, and reference materials for the flowcharts in this repository.

## Contents

- **Guides**: Step-by-step instructions and tutorials
- **References**: Technical specifications and standards
- **Index**: Catalog of all flowcharts with descriptions

## Creating an Index

Consider creating an `INDEX.md` file to catalog all your flowcharts:

```markdown
# Flowchart Index

## System Architecture

- [Main System Architecture](../flowcharts/architecture/main-system.eraserdiagram) - Overview of the entire system
- [Database Schema](../flowcharts/architecture/database.eraserdiagram) - Database design and relationships

## Process Flows

- [User Onboarding](../flowcharts/processes/onboarding.eraserdiagram) - New user registration flow
- [Payment Processing](../flowcharts/processes/payment.eraserdiagram) - Payment transaction workflow
```

## Best Practices

1. Keep documentation close to the diagrams they describe
2. Use relative links to reference flowcharts and exports
3. Update documentation when flowcharts change
4. Include rationale for design decisions
