# Example Exports

Export visual representations of the example flowcharts to this directory.

To export from Eraser.io:
1. Open your diagram in Eraser.io
2. Click the Export button
3. Choose PNG or SVG format
4. Save the file here with the same base name as your diagram file

Example:
- Source: `flowcharts/examples/simple-login-flow.md`
- Export: `exports/examples/simple-login-flow.png`
