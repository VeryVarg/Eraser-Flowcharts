# Exports

This directory contains exported visual representations of the flowcharts.

## Supported Formats

- **PNG** - Raster images for documentation and presentations
- **SVG** - Scalable vector graphics for web and high-quality prints
- **PDF** - Portable document format for printing and sharing

## Organization

Mirror the structure of the `flowcharts/` directory for easy reference:

```
exports/
  ├── project-alpha/
  │   ├── system-architecture.png
  │   ├── system-architecture.svg
  │   └── data-flow.png
  └── project-beta/
      └── process-workflow.png
```

## Naming Convention

Use the same base name as the source flowchart file:
- Source: `flowcharts/project/diagram-name.eraserdiagram`
- Export: `exports/project/diagram-name.png`
