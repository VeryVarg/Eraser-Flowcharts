# Flowcharts

This directory contains the source files for all flowcharts created with Eraser.io.

## Organization

Organize your flowcharts by creating subdirectories for different projects or categories:

```
flowcharts/
  ├── project-alpha/
  │   ├── system-architecture.eraserdiagram
  │   └── data-flow.eraserdiagram
  ├── project-beta/
  │   └── process-workflow.eraserdiagram
  └── general/
      └── decision-tree.eraserdiagram
```

## File Formats

- `.eraserdiagram` - Native Eraser.io diagram files
- `.md` - Markdown files with diagram code
- `.txt` - Plain text diagram definitions

## Adding New Flowcharts

1. Create your flowchart in Eraser.io
2. Export or save the diagram file
3. Add it to the appropriate subdirectory
4. Export a visual representation to `../exports/`
5. Create documentation using the template in `../templates/FLOWCHART_TEMPLATE.md`
